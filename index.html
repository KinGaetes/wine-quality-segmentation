Proceso reproducible

Una interpretación antes que una predicción.

El notebook contiene el desarrollo completo; esta página conserva las decisiones metodológicas que hacen legibles los resultados.

1

Preparar

Se elimina el índice exportado del CSV y se revisan 5.320 filas sin valores nulos en las variables usadas. Las escalas normalizadas se invierten para esta visualización.

2

Segmentar

La segmentación separa los perfiles con azúcar residual alto frente a su acidez estructural de los tintos y blancos no dulces. Es una regla de análisis, no una clasificación de mercado.

3

Contrastar

Se comparan relaciones, rangos de mejor calidad y agrupamientos químicos dentro de cada segmento. Así se evita presentar una señal promedio como si fuera universal.

Fuente original: UCI Wine Quality Dataset. El dataset contiene pruebas fisicoquímicas y puntajes sensoriales, pero no origen, marca, variedad, método de elaboración ni cata detallada.
